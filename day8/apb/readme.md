This project focuses on the design and verification of an Advanced Peripheral Bus (APB) slave using SystemVerilog. The APB slave supports read and write transactions, address decoding, wait-state generation through the PREADY signal, and error handling using PSLVERR. A complete layered verification environment was developed, including interface, transaction, generator, driver, monitor, scoreboard, environment, and test components. Randomized test scenarios were used to validate protocol compliance and data integrity, while the scoreboard compared DUT responses against a reference model to ensure functional correctness. This project demonstrates APB protocol implementation, functional verification methodologies, and SystemVerilog-based testbench development for digital design verification.
