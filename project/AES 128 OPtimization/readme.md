As part of my internship at TKM college of engineering, I worked on optimizing an AES-128 encryption core(taking https://github.com/Shehab-Naga/AES-128 this as ref) by implementing three key architectural improvements focused on reducing hardware utilization and power consumption. The original design employed a fully unrolled pipeline with ten dedicated AES round modules and ten separate key expansion units, resulting in high area overhead. To address this, I redesigned the architecture using an FSM-controlled iterative datapath that reuses a single AES Round module across all ten rounds, significantly reducing logic resources. I also implemented on-the-fly key expansion by replacing multiple key generators with a single reusable KeyExpansion module driven by an Rcon lookup table and round counter, eliminating the need to generate and store all round keys simultaneously. Additionally, I optimized the MixColumns stage through algebraic restructuring and shared intermediate computations, reducing logic depth and improving timing performance. These enhancements transformed the design into a compact, industry-style AES implementation that achieved substantial reductions in area and power while maintaining complete AES-128 functional correctness and meeting the target operating frequency of 100 MHz.
