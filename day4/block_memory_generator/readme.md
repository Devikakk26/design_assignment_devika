This design implements a simple 8×8 synchronous memory module using Verilog. The memory consists of eight locations, each capable of storing 8-bit data. An asynchronous active-low reset initializes all memory locations to zero. Data is written into the memory at a specified write address when the write enable signal is asserted, while stored data can be retrieved from a specified read address during read operations. The accompanying testbench verifies the functionality by writing different data values into all memory locations and subsequently reading selected locations to confirm correct storage and retrieval of data.
