A D Flip-Flop (DFF) is a fundamental sequential logic element used for storing a single bit of data. It captures the value present at the D (Data) input on the active edge of the clock signal and transfers it to the Q output, where it remains stored until the next clock edge. This edge-triggered behavior makes the D Flip-Flop an essential building block for registers, counters, shift registers, and memory circuits. The design is implemented in Verilog HDL and verified through simulation in Vivado, demonstrating correct data storage and synchronization with the clock signal.
