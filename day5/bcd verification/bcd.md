This work implements a BCD (Binary-Coded Decimal) Adder using **SystemVerilog**. The design performs the addition of two 4-bit BCD digits along with an optional carry input and produces a valid BCD sum and carry output. The circuit utilizes ripple carry adders and correction logic to ensure that the output remains a valid BCD representation whenever the binary sum exceeds 9. Functional verification was carried out using a **SystemVerilog interface-based testbench** in Vivado, where different input combinations were applied to validate the correctness of the sum and carry outputs. The simulation results confirmed the accurate operation of the BCD adder under various test conditions.
