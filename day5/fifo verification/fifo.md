This work implements an 8-bit synchronous FIFO (First-In-First-Out) memory using Verilog HDL. The design supports controlled data writing and reading operations through separate write and read enable signals while maintaining the order of stored data. Internal memory locations, read and write pointers, and status flags such as **full** and **empty** are used to manage FIFO operations efficiently. Functional verification was performed using a SystemVerilog interface-based testbench in Vivado, where multiple data values were written into the FIFO and later read back in the same sequence, confirming correct FIFO behavior and data integrity.
